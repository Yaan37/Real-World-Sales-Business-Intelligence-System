# Real-World Sales & Business Intelligence System 🚀

An end-to-end Python sales data system built to ingest raw transactional data, automate cleaning pipeline rules, perform multi-variable business analysis, and generate executive visual metrics.

## Features
- **Data Pipeline:** Automated missing value handling, duplicate removal, type casting, and standardizing metrics.
- **Business Intelligence:** Category performance, monthly revenue trends, discount impact analysis, and customer ranking via Pandas aggregation & grouping.
- **Data Visualization:** Automated Matplotlib visualizations for executive dashboards.

## Quickstart
```bash
pip install pandas matplotlib seaborn
python main.py
